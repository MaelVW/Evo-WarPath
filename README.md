# Evolutionary Warpath (Evo-WarPath)

## Installation

1. `Evo-WarPath-Setup.exe` herunterladen.
2. Doppelklick auf die Datei und „OK“ wählen.
3. Fertig: Das Spiel startet über die Verknüpfung **Evo-WarPath** auf dem Desktop oder im Startmenü.

Windows zeigt eventuell eine Warnung („Der Computer wurde durch Windows geschützt“), weil das Setup nicht signiert ist.
Dann auf **Weitere Informationen** und **Trotzdem ausführen** klicken.

- Installiert wird nach `%LOCALAPPDATA%\Programs\Evo-WarPath`, Administratorrechte sind nicht nötig.
- Systemvoraussetzung: Windows 10 oder 11 (64 Bit).

## Deinstallation

Einstellungen → Apps → **Evolutionary Warpath (Evo-WarPath)** → Deinstallieren.
Alternativ `Deinstallieren.cmd` im Installationsordner ausführen.

1/2/3 Waffen · E sprechen/benutzen · Esc Pausenmenü (dort steht die vollständige Tastenbelegung unter Optionen → Steuerung).
